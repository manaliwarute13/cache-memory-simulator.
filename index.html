Concepts Explained

Cache Hit: Requested address is already in the cache.

Cache Miss: Requested address is not in the cache.

FIFO: Removes the address that entered the cache first.

LRU: Removes the address that has not been used for the longest time.

Hit Ratio: (Cache Hits / Total Accesses) × 100

This educational simulator treats each number as a complete cache block address.
